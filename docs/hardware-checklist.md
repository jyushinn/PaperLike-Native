# 设备测试清单

## 支持状态

| 范围 | 状态 |
| --- | --- |
| 13.3K彩色版 | 部分显示、对比度及前光控制已做实机读回测试 |
| 13.3K黑白版 | 协议与模拟测试覆盖，未完成实机验证 |
| 触控 | 实验功能，需按型号、显示器排列和目标应用分别测试 |
| 长期运行与睡眠唤醒 | 需持续补充设备记录 |

## 测试前

记录应用版本、macOS版本、Mac架构、显示器型号和连接方式。保存当前配置和显示器参数；确保没有其他程序占用控制串口。

## 基础控制

- 分别检查视频、串口和触控识别状态。
- 单项修改显示模式、对比度和前光参数，核对设备读回，再恢复原值。
- 刷新速度无法读回，应记录物理观察，不能只凭界面数值判断。
- 检查连续拖动滑块后最终值是否正确，断开后有无继续发送控制命令。

## 自动化与恢复

- 测试普通、跨午夜、重叠及无匹配规则的时段。
- 检查手动覆盖、断开重连、系统时间变化和睡眠唤醒后的行为。
- 测试备份导出、文件选择取消、导入预览取消、导入失败及恢复运行。
- 在独立配置中测试损坏数据保留，避免破坏个人配置。

## 触控

- 测试单击、长按拖拽、抬手、惯性滚动及双指手势。
- 测试主副屏排列、缩放、竖屏、热插拔和校准。
- 在不同应用中验证缩放兼容映射；不将其记录为通用系统捏合。
- 断开或取消后不得留下按住的鼠标或修饰键状态。

## 画面驱动

- 修改前读取并保留原值，读取失败时不得继续写入。
- 检查手动恢复、退出、断线和目标显示器变化后的恢复。
- 驱动拒绝的选项应保持不可用或给出错误，不标记为设备支持。

## 报告

写明步骤、预期、实际结果和恢复状态，分别标注自动测试与物理观察。不要上传个人配置、设备序列号、原始私有采集或账号信息。
